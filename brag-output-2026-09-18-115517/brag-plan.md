# Brag Plan: Flick

## What is this app?
Flick is a native macOS launcher: Option+Space opens a dark HUD that searches apps, files, and commands without Spotlight.

## The angle
A letterpress print of the product site develops under the cursor — then the actual HUD types `saf` and Safari appears. Spotlight is the foil. The maze F is the stamp.

## Hook (first 2-3 seconds)
Giant ink type on paper: “Spotlight is slow.” Hold. Quiet.

## Key moments (the middle)
- Website hero line **Option+Space.** with the maze F, as on flick.web
- HUD in use: field types `saf`, Safari row lands
- Specimen keys: ⌥ Space / ↩ / Esc, one by one

## Outro / punchline
**Flick.** then **Take a copy.**

## User flow worth showing
Option+Space → type `saf` → Safari is the selected row.

## Tone
- Preset: polished
- Creative direction: letterpress product film of the website and the HUD
- Interpretation: long holds, paper and ink, no SaaS adjectives, one idea per scene

## Format: landscape — 1920x1080
## Duration: 20 seconds

## Visual identity (from the project)
- Background: #f4efe4
- Accent / ink: #141414
- Text: #141414 on paper; #f5f5f7 on HUD
- Display font: Palatino / Georgia (Cormorant stand-in, no network fonts)
- Body font: ui-monospace / SF Mono
- Strongest visual element: maze F logo + Option+Space headline + dark HUD

## Share copy (draft)
Option+Space. A native launcher for Mac — no Spotlight index.

## Audio direction
- Role: sparse professional accents
- Music: happy-beats-business-moves-vol-12-by-ende-dot-app.mp3
- Music treatment: start 0, volume 0.18, fade out last 1.2s
- Music cue guidance: bundled preset ~110 BPM. Strong cues: 3.27 (reveal), 8.74 (Safari), 17.47 (logo)
- Audio-reactive treatment: subtle; paper grain opacity and HUD glow breathe with RMS
- SFX posture: sparse; drop/click for HUD, soft impact for logo
- Audio-coupled moments: typed `saf`; key rows; logo stamp
- Restraint rule: no glitch, no punch, no casino fanfares
